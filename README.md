# 🛒 BazarDor (বাজার দর)

A modern, responsive Bengali grocery-price browsing web application built with **Next.js, TypeScript, and HeroUI**. Users can explore grocery products, browse categories, view product details, track rising and falling prices, and manage their accounts with secure authentication.

## 🌐 Live Demo

🔗 **Live Demo:** https://bazar-dor-green-eight.vercel.app/

## 🛠️ Technologies Used

- **Next.js** – React framework for building modern web applications
- **React** – Component-based user interface development
- **TypeScript** – Type-safe application development
- **HeroUI** – UI components and styling
- **Better Auth** – Authentication and session management
- **MongoDB** – Database integration and persistence
- **@better-auth/mongo-adapter** – MongoDB integration for Better Auth
- **Lucide React** – Modern icon library
- **React Icons** – Additional icons for the user interface
- **React Hot Toast** – Toast notifications and user feedback
- **React Marquee Text** – Scrolling text effects

## ✨ Key Features

### 1. 🛍️ Browse Grocery Products

Users can explore grocery products through a clean and user-friendly interface.

- Browse products on the home page
- View product cards with relevant information
- Explore available grocery items
- Navigate to individual product details

### 2. 📊 Price Trends

Discover products with changing prices through dedicated price-trend sections.

- Explore products with rising prices
- Discover products with falling prices
- Compare displayed product prices

### 3. 🗂️ Category-Based Browsing

Users can explore products by category and find relevant grocery items more easily.

- Browse different product categories
- Open dedicated category pages
- Explore products within a selected category

### 4. 📄 Product Details

Each product has a dedicated details page where users can explore information about an individual grocery item.

- View detailed product information
- Access product details through dynamic routing
- Navigate between the product listing and detail pages

### 5. 🔐 Authentication & Social Login

Users can create accounts and securely access their accounts using Better Auth.

- User registration and sign-in
- Google authentication
- GitHub authentication
- Session management


### 6. 👤 User Profile Management

Authenticated users can access their profile and manage their account information.

- View user information
- Access the protected profile page
- Update profile information
- Receive toast notifications for relevant actions

### 7. 📱 Responsive User Interface

The application provides a responsive interface designed for different screen sizes.

- 📱 Mobile
- 📲 Tablet
- 💻 Desktop

## 🎯 Project Highlights

- Reusable and modular React components
- Type-safe development with TypeScript
- Dynamic routing with Next.js
- Database persistence with MongoDB
- Authentication and session management with Better Auth
- Google and GitHub social authentication
- Protected profile access

## 📂 Main Pages

| Page | Description |
| --- | --- |
| `/` | Browse grocery products and explore price trends |
| `/category/[categoryId]` | Browse products by category |
| `/products/[productId]` | View individual product details |
| `/signin` | Sign in to an existing account |
| `/signup` | Create a new account |
| `/profile` | View and manage user profile information |

## 🏗️ Project Architecture

The application follows a component-based architecture with Next.js App Router. Product browsing, dynamic category and product routes, and authentication are organized into separate pages and reusable components.
